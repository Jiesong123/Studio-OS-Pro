# 产品视频

用于一次性的产品、品牌、广告和电商视频。读取 `knowledge/common/`、`knowledge/product/` 以及所选平台规则。

工作流：提炼受众和产品承诺 → 确定一个主要价值主张 → 选择证明/演示镜头 → 编写简洁旁白 → 设计产品细节和品牌安全画面 → 通过共享 Runtime 生成素材 → 渲染并检查 CTA、可读性、时长和画幅。

除非用户明确要求故事化广告，否则不要引入分集式角色弧线。
