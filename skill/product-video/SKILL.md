# 产品视频

用于一次性的产品、品牌、广告和电商视频。读取 `knowledge/common/`、`knowledge/product/` 以及所选平台规则。

工作流：提炼受众和产品承诺 → 确定一个主要价值主张 → 选择证明/演示镜头 → 编写简洁旁白 → 生成旁白、字幕和背景音乐计划 → 设计产品细节和品牌安全画面 → 通过共享 Runtime 生成素材 → 统一时间线和转场后渲染，并检查 CTA、可读性、时长、画幅、音量和转场。

除非用户明确要求故事化广告，否则不要引入分集式角色弧线。

产品镜头若包含手部演示、开合或移动，应使用关键帧序列保持产品形态，再补到目标帧率。静态展示不需要盲目增加关键帧；优先保证产品边缘、文字和品牌标识稳定。
