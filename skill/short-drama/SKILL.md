# 短剧

用于真人风格或一般连续短剧。读取 `knowledge/common/`、`knowledge/drama/` 和平台规则。

工作流：确定故事前提和类型 → 创建角色卡与关系卡 → 规划整季弧线和分集目标 → 围绕目标、障碍、升级、转折和悬念编写每集 → 创建场景/镜头表 → 对打斗或追逐动作拆分为单动作镜头和关键帧 → 绑定连续性状态和已确认参考素材 → 生成对白、旁白、字幕和音乐计划 → 只生成缺失镜头 → 检查剧情、视觉、音频和转场连续性 → 渲染单集。

镜头表不得只有 `visual_prompt`。人物动态镜头必须包含剧情节拍、开始情绪与结束情绪、开始动作状态、单一主要动作、动作发展、结束状态、屏幕方向以及与前一镜头的承接关系。

保持剧集、分集、角色、场景和镜头 ID 稳定，避免修改时重新生成已经确认的内容。

需要动作连续性时，按镜头速度规划关键帧并补到目标帧率。先生成中间动作状态，再进行 RIFE/FILM 等补帧；不要依靠重复图片或单次大跨度插值。失败时依据身份、动作、背景和重影指标有界重试。

需要进入混合 T2I→I2V/T2V 生产时，按 `docs/hybrid-production-contract.md` 填写生产字段，并运行导出程序生成项目圣经和镜头计划。
