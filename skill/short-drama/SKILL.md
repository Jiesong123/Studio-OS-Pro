# 短剧

用于真人风格或一般连续短剧。读取 `knowledge/common/`、`knowledge/drama/` 和平台规则。

工作流：确定故事前提和类型 → 创建角色卡与关系卡 → 规划整季弧线和分集目标 → 围绕目标、障碍、升级、转折和悬念编写每集 → 创建场景/镜头表 → 绑定连续性状态和已确认参考素材 → 只生成缺失镜头 → 检查剧情与视觉连续性 → 渲染单集。

保持剧集、分集、角色、场景和镜头 ID 稳定，避免修改时重新生成已经确认的内容。
