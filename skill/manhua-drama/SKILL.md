# 漫剧

用于动态漫画、漫剧、插画短剧和分格叙事。读取 `knowledge/common/`、`knowledge/drama/`、`knowledge/manhua/` 和平台规则。

工作流：确定视觉风格和分格语言 → 创建角色设定表与表情库 → 规划故事节拍和画格 → 生成并确认参考图 → 制作画格动画或图生视频镜头 → 保持人物、服装、道具和画风一致 → 检查画格可读性、运动连续性、字幕和集尾悬念 → 渲染。
