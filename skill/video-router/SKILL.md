# 视频路由器

在规划媒体任务前，先判断用户意图：

- 产品、品牌、广告、电商或功能展示 → `product-video`。
- 重复角色、分集、剧情、对白或真人短剧 → `short-drama`。
- 动态漫画、漫剧、动漫分格、角色插画或漫画叙事 → `manhua-drama`。

使用选中专业 Skill 的工作流和知识库。所有专业 Skill 共享 Box A Pipeline、Media Box 客户端、能力注册表、素材存储和渲染器。
