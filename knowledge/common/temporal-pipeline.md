# 时序生成与补帧

## 关键原则

- 关键帧负责设计动作过程，补帧负责把连续帧补到目标帧率；不要用重复静态图代替运动。
- 关键帧密度按动作速度调整：静态 1–2 张/秒，普通动作 2–4 张/秒，快速动作 4–8 张/秒。
- 如果相邻关键帧姿态差异过大，先增加中间姿态，再提高补帧倍数。
- 30fps 是输出规格，不是独立文生图数量。

## 无时序模型时的标准流程

1. 将镜头拆为 0.8–4 秒的单一动作。
2. 规划起始、蓄力、动作中段、接触/转折和结束姿态。
3. 用 IP-Adapter 保持身份，用 OpenPose/Depth 控制动作和空间。
4. 生成 5–10fps 的关键帧序列。
5. 使用 RIFE/FILM 补到 30fps；没有 AI 补帧时才使用 `ffmpeg minterpolate` 兜底。
6. 检查身份漂移、姿态跳变、重影、背景闪烁和只缩放不运动。

## 动态重试

- 人物变形：提高 IP-Adapter，固定参考图并降低动作幅度。
- 动作僵硬：降低 OpenPose/Depth 权重，减少同时启用的 ControlNet。
- 动作跳跃：增加关键帧并缩短镜头，而不是盲目提高补帧倍数。
- 补帧重影：降低单次补帧跨度，在碰撞、遮挡和爆炸处增加源关键帧。

参数必须受 Runtime 的上下界约束，并优先读取 Box B 的能力声明；本文件的数值是通用起始范围，不是特定模型保证值。
