# 漫剧动作与打斗序列

没有时序模块时，不要让一个镜头同时包含多个连续动作。每个镜头控制在 3～5 秒，只安排一个主要动作和一个摄影机运动。

推荐拆解为：对峙 → 起步/冲刺 → 第一次攻击 → 闪避或格挡 → 反击 → 能量/冲击高潮 → 拉开距离。每个镜头先确定起点姿态、终点姿态和空间方向，再生成关键帧。

先为每个镜头生成 4～6 张关键帧，保持同一角色参考图、种子、画风和场景；让 OpenPose、Depth 或 Lineart 控制图随时间变化，再生成中间过渡并合成。

人物身份可用 IP-Adapter Advanced 从 `weight=0.75～0.85` 开始；动作使用 OpenPose `0.75～0.90`；空间结构使用 Depth `0.45～0.65`；漫画像使用 Lineart `0.45～0.65`。每个镜头优先使用 1～2 个 ControlNet。

按“角色身份 → 场景 → 单一动作 → 摄影机 → 连续性约束”编写提示词。负面词包含角色变形、装甲变化、额外肢体、背景闪烁、纹理爬动、镜头跳切、动作瞬移、随机换装和文字水印。
